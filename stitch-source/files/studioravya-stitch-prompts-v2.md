# Studio Ravya — Business Site — Stitch Prompts (v2)

Generate **Home first** — Stitch locks style from the first screen. For every page after, start the prompt with "match the style of the previous screen."

This replaces the earlier mood-board version. Same solar brand identity, but every page now has to earn its place by moving a visitor toward "Start a Project" — the sun aesthetic sets the mood, the layout does the selling.

---

## Brand & Style DNA
- **Palette:** deep charcoal `#120E0A` base, radiant gold `#F5A623` and amber `#E8791A` accents, ivory `#FDF6EC` for light sections/body text, ember-red `#C1440E` used sparingly.
- **Typography:** bold serif (Fraunces/Canela) for headlines, clean geometric sans (Inter/General Sans) for body, nav, forms, and pricing tables.
- **Motifs:** thin radiating sun-ray dividers, circular/orb icons, soft radial gold glows behind key CTAs — used to mark trust/proof moments, not just decoration.
- **Tone shift from the concept-site version:** copy is direct and benefit-driven, not poetic. Every section states what the visitor gets, not just a mood.

## Global components (build once, reuse everywhere)
- **Nav:** sun-glyph + "STUDIO RAVYA" wordmark, links (Services dropdown, Work, Process, Pricing, Blog, About), solid gold "Start a Project" button, always visible.
- **Footer:** dark, four columns (Services list, Work/Blog, About/Privacy/Terms, social + contact email), sun-glyph mark, copyright.
- **CTA button style:** solid gold fill, dark text, subtle radial glow on hover.
- **Trust-signal strip:** thin horizontal band (logos, project count, or a one-line credibility statement) — reusable under any hero.

## 1. Home

```
Design a desktop-first web homepage for "Studio Ravya," a website and digital-product studio that builds sites and web apps for businesses. Palette: charcoal base (#120E0A), gold (#F5A623) and amber (#E8791A) accents, ivory (#FDF6EC) light sections. Serif headlines (Fraunces/Canela), clean sans body (Inter). Sun-ray line motifs and soft radial gold glows behind key CTAs.

Layout:
- Sticky nav: sun-glyph + wordmark, links (Services, Work, Process, Pricing, Blog, About), solid gold "Start a Project" button.
- Hero: dark section, radial gold glow behind a direct serif headline ("Websites and digital products, built to grow your business."), one-line subhead naming who this is for, gold "Start a Project" CTA + secondary "See Our Work" link.
- Trust strip directly under the hero: client logos or a one-line credibility statement (e.g. "X projects shipped since 2024").
- Services overview: 5 cards (Website Design & Development, Landing Pages, E-commerce, Brand & Web Identity, Custom Web Apps), each with an icon, one-line description, "Learn more" link.
- Featured case study: one large card — project image, problem/outcome one-liner, "View Case Study" gold button.
- Process teaser: 4-step horizontal strip (Discovery → Design → Build → Launch) linking to /process.
- Testimonial block: 1–2 client quotes in large serif type on a dark background.
- Closing CTA band: radial gold glow, "Let's build something that works," Start a Project button.
- Standard footer.
```
